#  Credit Conveyor – Auth Service

Микросервис аутентификации на **Spring Boot 3 + JWT**.  
Регистрация, логин, выдача токенов.

---

## 🧰 Стек
- Java 17, Spring Boot 3, Spring Security 6
- JWT (jjwt), PostgreSQL, Spring Data JPA
- Docker, Lombok, Maven
